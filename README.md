# 📖 About

NexBuddy is an all-in-one **social networking and activity matching platform** designed to help people build meaningful real-world connections through shared interests.

Instead of using different applications for finding travel partners, study groups, sports teammates, gaming friends, movie companions, or networking opportunities, NexBuddy brings everything together into a single platform.

Whether you're planning a trip, joining a football match, finding a study partner, organizing a movie night, or exploring local events, NexBuddy helps you discover like-minded people nearby.
